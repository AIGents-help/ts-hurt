# TS-HURT

**FEELINGS SOLD SEPARATELY.**

An Underground Print Operation. Custom Next.js storefront for print-on-demand apparel.

## Development

```bash
npm install
npm run dev
```

Checkout and POD fulfillment are **not yet connected**. No live orders should be accepted until checkout, webhooks, taxes, shipping, policies, and fulfillment have been validated.

Brand direction: industrial grunge, distressed ink, off-white, black, and red. Primary globe wordmark, underground-operation badge, and screen-print press mark.
